## Seko recommender examples

Eight composition/score pairs in `test/fixtures/build_fixture.jl` and
`test/fixtures/tiny_test.db` match examples in the
[sekocha/recommender README](https://github.com/sekocha/recommender/blob/a8b7f7bad284071dc5ccf38ed2081c3fbf9d45ff/README.md):

| Composition | Score |
| --- | --- |
| Al2Ba2O7Si1 | 0.74232 |
| Al2O12Si3Zn3 | 0.48140 |
| Al1Li1O12Si5 | 0.41613 |
| Al2Ba3O14Si4 | 0.39355 |
| Al2O14Si4Sr3 | 0.34611 |
| Zn1Mg3 | 0.39168 |
| Zn1Mg2 | 0.37147 |
| Mg1Zn4 | 0.26386 |

Some of these pairs also occur in README output, `examples/scored_compositions.tsv`,
`src/precompile.jl`, and the CLI, database and legacy-schema tests. These pairs
are upstream examples reused for software checks, not invented Eka predictions.
The other four rows in the tiny fixture are project-authored test cases.
`docs/production-validation.md` separately records observations from querying the
upstream database; it is not evidence of predictions generated by Eka.
